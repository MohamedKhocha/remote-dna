## `raw/` — الأصول (غير مرفوعة)

كل اللقطات الأصلية بدقة 1080×2400 محفوظة في `raw/`، وهو **مُستثنى في `.gitignore`**
فلا يصل GitHub إطلاقاً. للاستبدال: اختر لقطة من `raw/` وصدّرها بنفس الاسم أعلاه.
